# Feature Parity

| Capability | Target | Current |
|---|---|---|
| Local-only operation | Required | Architecture defined |
| Android ↔ Windows files | Required | Core streaming primitive only |
| Explicit receive consent | Required | Protocol/state contract defined |
| Discovery plus fallback | Required | Domain validation only |
| Secure pairing | Required | Consent state machine only |
| Integrity verification | Required | Rust streaming SHA-256 implementation |
| Resume/cancel | Required | Protocol cancellation name only |
| Gesture controls | Optional enhancement | Not implemented |
| Button controls | Mandatory | Not yet connected in apps |
| Installable artifacts | Required for release | Not produced |

This table is a status record, not a claim of product parity.
