# Project

ABOT is a local-first, open-source Android-to-Windows file-transfer application. Its visual brand is `abot.`, its tagline is “Abot mo, salo ko.”, and its required stack is Kotlin/Compose on Android, Tauri/React on Windows, Rust core libraries, and a versioned shared protocol. Conventional controls are mandatory; camera gestures are optional intent controls.

Current phase: repository initialization and executable core contracts. See `docs/roadmap.md` for verified status.
